## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- A free [Gemini API Key](https://aistudio.google.com/apikey)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/gemini-app.git
cd gemini-app

# Install dependencies
npm install

# Create environment file
echo "REACT_APP_MY_API_KEY=your_api_key_here" > .env

# Start development server
npm run dev
```

> 💡 **Tip:** Get your free API key from [Google AI Studio](https://aistudio.google.com/apikey)

## 🎯 Usage

1. **Start a conversation** - Type your prompt and press Enter
2. **Continue chatting** - Send multiple messages in the same session
3. **New Chat** - Click the + button to start a fresh conversation
4. **Load History** - Expand the sidebar to access previous chats
